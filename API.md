# API Reference

Full interactive docs (OpenAPI/Swagger) are auto-generated by FastAPI at `/docs` when the
backend is running (`http://localhost:8000/docs`). This file is a quick-reference summary — the
running `/docs` (or `/openapi.json`) is the source of truth for exact schemas.

Base URL: `http://localhost:8000` (default; configurable via `NEXT_PUBLIC_API_BASE_URL` on the
frontend side).

## Health

`GET /api/health` → `{status, app, environment, data_source_mode, timestamp}`

## Data

- `GET /api/data/prices?series=<name>&series=<name>&tail_days=500` → price history for the
  requested series (all series if `series` is omitted), plus `data_quality`.
- `GET /api/data/operational?tail_days=500` → demand/utilisation/freight/project-delay history.

## Forecasting (`backend/app/api/forecasting.py`)

- `GET /api/forecasting/series` → available series names and model names.
- `POST /api/forecasting/forecast`
  ```json
  {"series_name": "crude_brent_usd_bbl", "model": "ensemble", "horizon_days": 90}
  ```
  → `{series_name, model, dates[], point_forecast[], lower_90[], upper_90[], governance}`.
  Also writes a best-effort audit row (see ARCHITECTURE.md).
- `POST /api/forecasting/backtest`
  ```json
  {"series_name": "naphtha_usd_ton", "model": "xgboost", "horizon_days": 30,
   "min_train_days": 365, "step_days": 30, "max_windows": 12}
  ```
  → per-window metrics + pooled `aggregate_metrics` (MAE/RMSE/MAPE/directional
  accuracy/interval coverage).

`model` must be one of the values returned by `GET /api/forecasting/series` (`naive`,
`moving_average`, `arima`, `xgboost`, `lightgbm` if available, `ensemble`). An unknown model or
series returns `400` with a message listing the valid options.

## Feedstock economics (`backend/app/api/feedstock.py`)

- `GET /api/feedstock/profiles` → available feedstock names.
- `POST /api/feedstock/economics` — single-scenario economics (see `EconomicsRequest` schema in
  DATA_DICTIONARY.md for fields) → full revenue/cost/margin/EBITDA breakdown.
- `POST /api/feedstock/compare`
  ```json
  {"scenarios": {"ethane_base": {...}, "naphtha_base": {...}}}
  ```
  → ranked comparison table (best contribution margin per ton ethylene first).
- `POST /api/feedstock/switch-point`
  ```json
  {"scenario_a": {...}, "scenario_b": {...},
   "price_min_a": 5, "price_max_a": 15, "price_min_b": 400, "price_max_b": 900,
   "grid_points": 25}
  ```
  → 2D sensitivity grid (`grid_points²` rows) of contribution-margin difference across both
  feedstocks' price ranges, with a `preferred` column per grid point.

## Error handling

All validation errors return HTTP 400 with a plain-English `detail` message (unknown series,
unknown model, unknown feedstock, or a switch-point price range with no break-even). Pydantic
request validation errors (wrong types, out-of-range values) return HTTP 422 with FastAPI's
standard validation error format.
